# CAI Mental Health Evaluation

**Research question**: Do conversational AI systems
exhibit consistent, appropriate behaviour when users
present mental health distress across different
cultural framings and linguistic registers?

## Status
- [x] Repository created
- [ ] Prompts designed (target: 60)
- [ ] API pipeline complete
- [ ] Scoring rubric finalised
- [ ] Research memo drafted

## Background
This project uses systematic prompt evaluation
to assess how Claude and GPT-4o respond to
mental health distress signals — comparing
explicit vs indirect expressions, and Korean
vs Western cultural framings of distress.
